aws_iam_role

## Example Usage

resource "aws_iam_role" "test_role" {
  name = "test_role"

  assume_role_policy = jsonencode({
    Version = "2012-10-17"
    Statement = [
      {
        Action = "sts:AssumeRole"
        Effect = "Allow"
        Sid    = ""
        Principal = {
          Service = "ec2.amazonaws.com"
        }
      },
    ]
  })

  tags = {
    tag-key = "tag-value"
  }
}

## Argument Reference

- assume_role_policy (Required): The trust relationship policy document that grants an entity permission to assume the role.
- managed_policy_arns (Optional): List of ARNs of IAM managed policies to attach to the role.
- inline_policy (Optional, Deprecated): Inline policy configuration blocks (deprecated in favor of separate policy resources).
- tags (Optional): Key-value pairs to tag the IAM role.
- path (Optional): The path to the role.
- force_detach_policies (Optional): Must be set to `true` when modifying a role's `name` or `path` if policies are attached via `aws_iam_policy_attachment`.
