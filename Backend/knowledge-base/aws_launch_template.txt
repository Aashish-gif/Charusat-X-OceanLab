aws_launch_template

## Example Usage

resource "aws_launch_template" "example" {
  name = "example"

  block_device_mappings {
    device_name = "/dev/sdf"
    ebs {
      volume_size = 20
    }
  }

  capacity_reservation_specification {
    capacity_reservation_preference = "open"
  }

  cpu_options {
    core_count       = 4
    threads_per_core = 2
  }

  credit_specification {
    cpu_credits = "standard"
  }

  disable_api_stop        = true
  disable_api_termination = true
  ebs_optimized           = true

  iam_instance_profile {
    name = "test"
  }

  image_id      = "ami-test"
  instance_type = "t2.micro"
  key_name      = "test"

  metadata_options {
    http_endpoint               = "enabled"
    http_tokens                 = "required"
    http_put_response_hop_limit = 1
    instance_metadata_tags      = "enabled"
  }

  monitoring {
    enabled = true
  }

  vpc_security_group_ids = ["sg-12345678"]

  tag_specifications {
    resource_type = "instance"
    tags = {
      Name = "test"
    }
  }

  user_data = filebase64("${path.module}/example.sh")
}

## Argument Reference

- name (Optional): The name of the launch template (auto-generated if blank).
- name_prefix (Optional): Creates a unique name with specified prefix.
- description (Optional): Description of the launch template.
- region (Optional): Region where the resource will be managed.
- default_version (Optional): Default version of the launch template.
- update_default_version (Optional): Whether to update default version each update.
- image_id: The AMI from which to launch the instance.
- instance_type: The type of the instance.
- key_name: The key name to use for the instance.
- user_data: Base64-encoded user data to provide when launching.
- iam_instance_profile: The IAM Instance Profile to launch with.
- instance_initiated_shutdown_behavior: Shutdown behavior (stop or terminate).
- block_device_mappings: Volumes to attach besides AMI volumes.
- ebs_optimized: Whether the instance will be EBS-optimized.
- ram_disk_id: The ID of the RAM disk.
- kernel_id: The kernel ID.
- vpc_security_group_ids: List of security group IDs to associate.
- security_group_names: List of security group names to associate.
- network_interfaces: Customize network interfaces at boot time.
- secondary_interfaces: Secondary interfaces to associate.
- private_dns_name_options: Instance hostname options.
- cpu_options: CPU options for the instance.
- credit_specification: Credit specification for the instance.
- monitoring: Monitoring option for the instance.
- metadata_options: Customize metadata options.
- capacity_reservation_specification: Targeting for capacity reservations.
- placement: Instance placement configuration.
- license_specification: License specifications to associate.
- instance_market_options: Market/purchasing options.
- enclave_options: Enable Nitro Enclaves.
- hibernation_options: Hibernation options.
- disable_api_termination: Enable EC2 Instance Termination Protection.
- disable_api_stop: Enable EC2 Instance Stop Protection.
- tag_specifications: Tags to apply to resources during launch.
- tags: Map of tags to assign to the launch template.
